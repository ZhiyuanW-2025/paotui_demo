# 校内搭把手 · 校园跑腿互助平台

面向作品展示的完整交互 Demo。React 19 + TypeScript + Vinext / Vite，蓝、橙、黄主题，支持电脑和手机布局。学校、人物、身份认证、位置与支付均为模拟。

## 本地启动

需要 Node.js 22.13 或以上版本，推荐 Node.js 24。

```bash
git clone https://github.com/ZhiyuanW-2025/paotui_demo.git
cd paotui_demo
npm ci
npm run dev
```

已有本地项目可进入项目文件夹后直接运行 `npm run dev`。

预览地址：**http://127.0.0.1:5188/**

保持终端运行，按 `Ctrl+C` 停止。默认端口为 5188；如占用可运行 `npm run dev -- --port 5189`，以终端输出的地址为准。`localhost` 和 `127.0.0.1` 的浏览器存储各自独立，演示时建议统一使用上述地址。

## 功能

- 任务大厅：分类、搜索、校园区域、酬谢范围筛选；最新、距离、截止、酬谢排序。
- 动态发布：按任务类型展示字段；常用校园地点、快捷时限、无偿互助。
- 履约：接单、取消、超时提醒、双方确认延期、完成说明与图片凭证、发布者验收、星级评价。
- 任务聊天：文字、图片与快捷回复；当前任务双方可见；取消后重新接单时开启新聊天，旧聊天仅发布者和演示管理端可查看。
- 费用：商品本金与酬谢独立记账；商品预算变更确认；预付与垫付；模拟支付处理中和成功界面；线下付款标记与收款方确认；避免重复付款。
- 信用：校园认证、历史完成数、履约率、评价、已确认违约；进行中的任务不拉低履约率；同一任务完成和责任不重复计入。
- 消息中心：接单、聊天、完成、取消、费用确认等站内通知和未读提示；15 分钟内到期与超时持续提醒。
- 五所虚拟学校：按 `schoolId` 隔离用户、任务、聊天、通知；模拟坐标与圆形校园围栏匹配；距离采用球面直线估算。
- 演示管理端：申诉、时间线、聊天与凭证查看、责任认定、恢复履约。
- 数据：保存在当前浏览器 localStorage，刷新后保留；同源多标签页通过 storage 事件同步，Web Locks 锁保护接单等写入事务。

## 答辩快速演示

点击右上角「作品演示」，选择三条剧情之一。会创建独立任务，不会覆盖已有任务。

### 1. 顺利完成

1. 创建基础剧情，默认身份是发布者「林小满」。
2. 详情页点击「切换身份」，以「程一诺」接单。
3. 打开任务聊天，发送消息；可切换双方回复。
4. 跑腿者点击「提交完成凭证」，可上传图片或使用演示凭证。
5. 切回发布者，确认验收。
6. 在费用结算中体验模拟支付，查看账单，留下评价。

### 2. 代购变更

1. 创建代购剧情，切换跑腿者接单。
2. 点击「确认 / 变更商品费」，输入实际商品费和原因。
3. 切换发布者确认费用，再切回跑腿者上传凭证。
4. 发布者验收后分别结算商品费与酬谢。
5. 可选择「标记线下已付」，再切换跑腿者确认收款。

新建代购任务时也可以选择「发布者预付商品费用」，演示购买前预付，及费用增加后的差额补付。

### 3. 异常处理

1. 创建异常剧情，任务已由程一诺接单并模拟超时。
2. 可申请延期并由对方确认，或取消，或提交申诉。
3. 提交争议后，前往「争议处理」查看时间线、任务聊天与凭证。
4. 点击「处理争议」，模拟管理员认定责任并填写处理结论。
5. 处理后任务恢复至进行中或待验收，可继续履约。确认违约会在责任人的个人中心显示。

已发生付款的任务会阻止直接取消，需先通过申诉协商。本版管理端演示责任认定与继续履约，不模拟退款清算。

## 学校与身份切换

左上角学校名称可以切换五所学校、设置校内模拟位置，或手动输入坐标测试围栏。超出所有校园的坐标会提示无法匹配。

头像可以切换本校四个演示身份，其中「许知夏」是无历史记录的新同学，可正常接单。

个人中心可以重置全部五校演示数据。确认重置后聊天、图片、任务与账单都会恢复初始状态。

## 检查与构建

```bash
npm run check
npm test
npm run build
```

构建成功后可以通过 `npm start` 启动本地生产预览，具体地址以终端输出为准。产物包括 `dist/client` 和 `dist/server`，后者为 Cloudflare Worker 运行形式。未来绑定 shuge.work 时需要配置支持 Worker 的托管或调整输出方式；当前没有发布或修改域名。

## 代码结构

- `app/page.tsx`：任务大厅、详情、发布、聊天、支付和演示管理界面。
- `app/globals.css`：设计样式与响应式布局。
- `lib/demo.ts`：数据模型、地理匹配、种子数据、状态转换和操作权限。
- `tests/workflow.test.ts`：并发接单语义、跨校隔离、结算、履约、争议和隐私回归测试。
- `public/demo-proof.svg`：不含隐私数据的演示凭证。

## 演示边界

这是浏览器内演示，不含真实账号系统、学生认证、支付网关、短信推送或服务端数据库。不同设备不共享数据，管理端为公开的演示入口；不要用于真实交易或填入真实个人信息。Web Locks 在当前浏览器的同一来源下协调写入，不替代正式上线所需的数据库事务与服务端权限校验。
